# Redux Logic

## Description

This skill enables efficient state management using Redux Toolkit (RTK), including advanced slice logic and middleware integration.

### Capabilities

1. **Slice Creation**:
   - Use `createSlice` for state.
   - Write reducers that update the store efficiently.

2. **Async Logic**:
   - Use `createAsyncThunk` to handle side effects.
   - Create reusable actions for fetching or posting data.

3. **Middleware**:
   - Integrate custom middleware when necessary.

4. **Integration**:
   - Add slices to the store dynamically.
   - Combine RTK with other tools like redux-logger.

---

This skill ensures front-end consistency and aligns with the repository’s `AGENTS.md` state management guidelines.
